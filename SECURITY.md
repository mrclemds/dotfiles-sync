# Security Policy

## Supported Versions

Security fixes are made on `main` and backported to supported `release/*`
branches when they are compatible. Users should run the latest published
release.

## Reporting a Vulnerability

Use [GitHub private vulnerability reporting](https://github.com/mrclemds/dotfiles-sync/security/advisories/new).
Do not disclose suspected vulnerabilities in public issues, pull requests, or
discussions.

Include the affected version, a minimal reproduction, impact, and any suggested
mitigation. The maintainer will acknowledge reports within seven days and will
coordinate disclosure after a fix is available.
